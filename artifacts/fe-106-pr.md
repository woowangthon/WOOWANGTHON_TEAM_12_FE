# 권장 PR 본문

AI 작업을 시작한 화면을 떠나면 진행 상황과 완료 결과를 찾기 어려웠습니다. 로그인한 앱의 공통 레이아웃에서 작업을 조회하고, 상단 표시와 사이드바에서 진행 중인 일·소식을 열 수 있게 합니다. 예를 들어 자료 분석 중 지원 화면으로 이동해도 상태를 확인하고, 완료·실패 소식에서 해당 자료의 분석 상세로 돌아갈 수 있습니다.

- SPEC: R-04 F-10 S-47. Closes #106.
- 실제 `GET /api/work` 사용: 진행 중 3초, 유휴 30초. 숨겨진 탭은 요청을 취소하고 멈추며, 다시 보이면 즉시 조회합니다. 요청 완료 후 다음 조회를 예약하며, 인증 만료·로그아웃·언마운트 시 이전 응답을 적용하지 않습니다.
- 다섯 종류와 `QUEUED`, `ANALYZING`, `RUNNING`, `WAITING_CONFIRM`을 표시합니다. 완료(`COMPLETED`, `DONE`)와 실패(`FAILED`, 오류 코드)를 구분합니다. 최근 24시간·최대 20개는 서버 응답을 그대로 따릅니다.
- 안 읽음은 `finishedAt > seenAt`입니다. 목록을 연 순간 표시한 가장 늦은 `finishedAt`만 `POST /api/work/seen`으로 보냅니다. 현재 시각을 보내지 않으며, 이후 도착한 소식은 다음에 열기 전까지 안 읽음으로 남깁니다. 늦게 도착한 GET과 읽음 POST의 순서, 다른 기기의 읽음 변경, 밀리초 이하 시각 정밀도를 처리합니다.
- 자료는 기존 `/experience` 화면의 `workJob` 조회로 분석 상태·결과 활동·기존 재시도 API에 연결합니다. 문항은 기존 `question` 선택과 답·초안 영역에 연결합니다.
- 차곡이는 기존 FE #99 패널에서 서버 `runId`를 읽어 단계와 확인 카드를 복원합니다. 문항이 없거나 삭제된 경우에도 작업을 열 수 있습니다. 새로고침 후에도 복원하며, 확인·생성·재시도는 사용자가 눌러야 실행됩니다.
- 기존 화면별 상세 폴링 간격과 409 선택지 구현을 유지합니다. 푸시·메일·새 AI 생성 기능은 추가하지 않습니다.
